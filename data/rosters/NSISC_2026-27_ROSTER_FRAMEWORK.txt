HOW TO FILL
--------------------------------------------------------------------------------
Columns are pipe-delimited so this parses cleanly later.

  NAME | CLASS_26_27 | HOMETOWN | EVENT_GROUP | SCY_EVENT | TIME | SOURCE

  CLASS_26_27  So/Jr/Sr/5th — PROJECTED unless marked CONFIRMED
  EVENT_GROUP  as published by the school's roster page
  SCY_EVENT    add one row per event you have a time for
  TIME         mm:ss.hh or ss.hh. Write UNKNOWN if none. NEVER write 0.
  SOURCE       swimcloud URL, or meet name + date

Add rows freely. Delete nobody — if an athlete turns out to have left, mark
them DEPARTED in CLASS_26_27 rather than deleting, so the diff stays auditable.

SCORING-PROJECTION NOTES (for when the times are filled)
================================================================================
1. NSISC entry cap is TOTAL-ONLY: max 7 events per swimmer, any individual/relay
   mix. No separate per-type caps. Already encoded in the NSISC preset as
   maxTotalEntriesPerSwimmer = 7.
2. The 2025 New South men's championship had only FOUR programs. Small field =
   depth matters disproportionately; a team's 3rd and 4th scorer in an event is
   often the difference. Do not project from top-end times alone.
3. Divers are listed here but SwimCloud will not have swim times for them. Leave
   diving entries as UNKNOWN rather than 0 — a 0 would score as a real result.
4. Do NOT extrapolate a returner's 2026-27 time from their 2025-26 time. Repo
   rule: no interpolation, extrapolation, projection or estimation of a
   competition value. Use the actual best time on file and let the engine
   handle the comparison.
5. When you add these teams' athletes to a workspace, both schools already exist
   in teamDivisions.ts as active D2 with both genders sponsored — no new entry
   needed, and no `provenance: 'legacy'` (banned).
