Omniswim SwimCloud Companion

The auto-fetch crawl (Track A′) posts each captured page to Omniswim Suite's local server. That server requires a pairing token so no other page you visit can write into your capture store.

Find it in Omniswim Suite's own startup console banner, under "SwimCloud capture routes" — look for the line starting "Pairing token:". It is also written to data/swimcloud-pairing-token.json.

Matches the app's PORT/OMNI_PORT. Defaults to 3000.
